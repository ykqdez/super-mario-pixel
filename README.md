# 超级马里奥：橡果王国大冒险 (Super Mario Pixel)

纯前端零依赖开发的 16-bit 横版像素风马里奥冒险游戏，支持电脑键盘、手柄以及**手机横屏多点触控**，可直接部署至 GitHub Pages 在线游玩。

## 特色玩法
- **4 大主题关卡 + 隐藏水管子区域 + 世界大地图**：橡果蘑菇草原（1-1）、幽深水晶矿洞（1-2）、云端橡树浮岛（1-3）、酷霸王熔岩堡垒（1-4 Boss 战）及奇诺比奥宝箱屋。
- **进阶操作**：可变高度跳跃、贴墙滑行与蹬墙跳、空中下砸（Ground Pound）、钻水管。
- **4 种变身与备用道具盒**：超级蘑菇、火焰花、**超级橡果**（空中滑翔、二段升空、360°尾旋）、无敌星星。
- **手机横屏专属优化**：自动识别触屏设备并显示多点触控十字方向键与右拇指功能键（支持滑动换向与连按冲刺跳）、刘海屏安全区适配、横屏全屏自适应及竖屏旋转提示。

## 操作说明
- **电脑端**：`A/D` 或 `←/→` 移动，`Space/W/Z/K` 跳跃/滑翔，`Shift/J/X` 冲刺/火球/尾旋，`S/↓` 下蹲/进水管/空中下砸，`E/C` 释放备用道具，`P/Esc` 暂停。
- **手机端**：横屏打开页面自动显示左侧十字键 + 右侧「跳」「冲/攻」「道具」「暂停」虚拟手柄，菜单与宝箱可直接点按屏幕交互。

## 本地运行与测试
- 双击 `start_game.bat` 或直接在浏览器中打开 `index.html` 即可开始游玩。
- 自动化校验：`node tests/verify.cjs`
